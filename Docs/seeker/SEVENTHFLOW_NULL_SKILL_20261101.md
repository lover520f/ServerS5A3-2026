# 第七翼动对象初始化空技能修复

分类：功能修复。状态：V201 与已发布累计客户端原生对照通过，发行及游戏实测待完成。

## 问题与证据

匹配正式 V201 的异常上下文显示，场景对象初始化调用技能查询后得到 NULL，继续调用技能数值函数，最终读取地址 `0x00000F9C`。模块 SHA256 为 `b965e2d1d04b4679eba1ba00de6bbceacdc1ccab8789ea22bef98a28f61283d5`；故障 RVA 为 `0x033DF6A3`。

原生调用链为对象初始化 `0x02C8A690` → 技能查询虚表槽 `0xBDC`（参数 130、1）→ `0x02947D20` → `0x02930A20` → 故障。初始化函数只检查所属角色转换成功，未检查技能查询结果。匹配 PVF 将对象 38801、38802 分别映射为 `Character/Gunner/SeventhFlow.obj`、`SeventhFlowFinish.obj`；故障栈走的是 38801 分支。此证据定位技能对象异常，不能将玩家同时拾取的操作直接等同于其触发原因。

实际角色技能 getter `0x02773700` 在技能目录/缓存缺失、特定角色类型或技能页无效时可正常返回 NULL。回归直接执行该 getter，而非强制替换其返回值。现场数据未包含完整角色与技能表，所以尚不能区分当时是哪一种返回条件。

## 最小修复

在技能 getter 返回后、访问技能对象前增加空值检查。空值走本初始化函数已有的栈恢复出口，保留此前基础初始化；有效技能继续执行完整原指令、两种对象分支及数值写回。保留寄存器、标志和调用约定。不修改共用数值解码器，不虚构技能等级或伤害，不修改 PVF、物品归属或拾取事务。

仅新增独立补丁工具、对应原生回归、本技术说明与独立变更记录。工具验证精确输入摘要和机器码指纹，输出新候选，保留累计客户端其他字节。发行时使用最新已批准累计版本，不以旧复现输入覆盖新版本。

## 验证与验收

- 原始机器码在空技能场景复现相同故障地址与指令；候选正常返回。
- 38801/38802、有效/缺失技能、缺失所属角色、相关对齐分支和寄存器/栈恢复进行对照。
- 核对输入只读、输出独立、变化范围、PE 结构与累计补丁保持；错误输入拒绝。
- 最终仍须玩家组队使用第七翼动，覆盖施放者和队友观察者、连续施放、拾取和换房。自动回归不代表游戏实机验收。

现有回归共 50 组：两个对象编号 × 五种对象对齐 × 五种技能/所属角色状态。30 组空技能原版均在相同指令读 `0xF9C` 失败、候选正常退出；10 组有效技能与 10 组所属角色缺失的原版/候选结果完全一致。另拒绝截断、摘要改变和重复补丁三种输入。

相同 50 组已在最新核验的累计输入 `534b5ef166d0090d1ab88e01f5f443721abf97eabfacfb007e04e30fd9d51b24` 上再次通过。七处相关完整函数/虚表窗口与 V201 相同。累计候选为 `6091f9ac92e588643226a8f61d313cb798b308d530bf3013cab0bda1d0cd0ece`，112545792 字节；仅原七字节、必要 PE 头与新增 `.sfnull` 节改变，其余累计字节保持。两套候选的 Windows 无执行映像映射、PE checksum 与通知工具只读结构校验均通过。
