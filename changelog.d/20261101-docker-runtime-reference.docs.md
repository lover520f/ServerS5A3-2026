# 公开 Docker 运行配置参考与部署排查入口

## 变更

- 提供可下载的脱敏环境配置参考，说明客户端上下行协议参数、实例源到生成文件的关系、资源路径和凭据替换范围。
- 部署指南突出普通／魂大会的 vendor 开关与赛马关闭要求，并提供只输出指定参数的实际游戏进程核对命令。
- 保留各实例的运营策略，真实运行目录、地址、凭据和玩家资料不进入公开示例。

## 验证

- 配置示例与当前 Docker 生成器映射核对；文档相对链接、示例 JSON／Python 语法、隐私内容及变更片段检查通过。
- 本次仅新增参考文件与文档入口，不修改服务运行逻辑，不执行部署或服务中断。
